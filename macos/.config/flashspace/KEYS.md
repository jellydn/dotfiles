# FlashSpace keys

Workspaces are **Option + the first letter**. Assign is the same letter with **Ctrl+Opt+Cmd**.

```
         opt + letter     →  switch workspace
  ctrl + opt + cmd + letter  →  put the front app on that workspace
```

## Workspaces

External 4K (`S24R35xFZ`) — focused work:

| Key | Workspace | Remember | Apps |
| --- | --- | --- | --- |
| `opt+c` | **C**ode | code | VS Code Insiders, Zed, Xcode-beta, Amp, Grok Bot, ChatGPT, Waku, Delta |
| `opt+b` | **B**rowser | browse | Brave, Zen, Chrome, Safari |
| `opt+t` | **T**erminal | terminal | Alacritty, Termius |
| `opt+e` | **E**mail | email | Canary Mail |
| `opt+g` | Tools | **g**ear / gadgets | OrbStack, Notes, Navicat, ChatGPT Classic, Vial, Karabiner, Preview, Headlamp, PHP Monitor, FileZilla, Calendar, Reminders |

Laptop — comms and downtime:

| Key | Workspace | Remember | Apps |
| --- | --- | --- | --- |
| `opt+w` | **W**ork | work chat | Slack, Teams |
| `opt+m` | Chat | **m**essages | Telegram, Messages |
| `opt+r` | **R**elax | relax | Discord, Spotify |

Always visible (floating): Finder, System Settings, FlashSpace, Tuna.

## Other

| Key | Action |
| --- | --- |
| `opt+tab` | Workspace switcher (this display) |
| `ctrl+opt+shift+tab` | Space Control grid (this display) |
| `ctrl+opt+cmd+h/j/k/l` | Focus left / down / up / right |
| `ctrl+opt+cmd+u` / `i` | Previous / next app in workspace |
| `ctrl+opt+cmd+p` / `n` | Previous / next window in workspace |

`opt+letter` never fights Tuna: Tuna uses **Hyper** (`ctrl+opt+cmd+shift`) or Combo, not Option alone.

Config: `macos/.config/flashspace/profiles.json`
